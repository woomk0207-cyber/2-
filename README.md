# 2인 대전 게임

친구와 한 키보드로 즐기는 1:1 아레나 슈팅 대전 게임입니다. 3판 먼저 이기면 승리!

## 실행
`index.html`을 브라우저로 열면 됩니다.

## 조작
| | 이동 | 발사 |
|---|---|---|
| P1 | W A S D | F |
| P2 | 방향키 | L |

- 마지막으로 움직인 방향으로 총알이 나갑니다.
- 총알 10발을 맞으면 라운드 패배 (체력 100).
- Enter: 다음 라운드 / R: 새 경기

## 파일
- `index.html` – 화면 구조
- `style.css` – 스타일
- `game.js` – 게임 로직
